What it does

Compare latency across hosts, inspect percentiles, and trace failures. The colored terminal is rendered by the project’s Rust Ratatui widgets.

What it targets

The native app monitors IP addresses and domains using ICMP and DNS. This browser demo supplies synthetic data because browsers cannot open raw ICMP sockets.
